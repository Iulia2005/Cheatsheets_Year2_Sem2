How Java Works

  • You write .java source code
  • javac compiles it to .class (bytecode)
  • The JVM runs bytecode on any OS
  • JRE = JVM + libraries  |  JDK = JRE + compiler

Write once, run anywhere → platform independence.

Loops

§04

for loop

Known iterations
for (int i = 0; i < 5; i++) {
  System.out.println(i);
}
// prints 0, 1, 2, 3, 4

while loop

Unknown iterations
int result = -1;
while (result < 0 || result > 100) {
  System.out.print("Enter 0-100: ");
  result = sc.nextInt();
}
// keeps asking until valid

do…while loop

Runs at least once
char again;
do {
  // program logic
  System.out.print("Again? (y/n): ");
  again = sc.next().charAt(0);
} while (again == 'y');

break & continue

for (int i = 0; i < 10; i++) {
  if (i == 5) break;    // exit loop
  if (i % 2 != 0) continue; // skip odd
  System.out.println(i); // 0, 2, 4
}

Anatomy of a Method

// modifier returnType name(params)
static double addTax(double price, double tax) {
  return price * (1 + tax / 100);
}

// void = returns nothing
static void greet(String name) {
  System.out.println("Hi, " + name);
}

Calling & Overloading

double total = addTax(100.0, 19.0); // call
greet("Bob");

// Overloading: same name, diff params
static int    add(int a, int b)       { return a+b; }
static double add(double a, double b) { return a+b; }
static int    add(int a, int b, int c){ return a+b+c; }

Pass-by-Value

  • Primitives: method gets a copy — original unchanged
  • Arrays/Objects: method gets a reference — original can change

int a = 5;
demo(a);
// a is still 5!

Common Array Algorithms

// Max value
int max = arr[0];
for (int i = 1; i < arr.length; i++)
  if (arr[i] > max) max = arr[i];

// Sum
int sum = 0;
for (int v : arr) sum += v;

// Search (returns index or -1)
int find(int[] arr, int target) {
  for (int i = 0; i < arr.length; i++)
    if (arr[i] == target) return i;
  return -1;
}

OOP – Classes & Objects

§07

Class Template

public class BankAccount {
  // Fields (private = encapsulation)
  private String name;
  private double balance;

  // Constructor
  public BankAccount(String name) {
    this.name = name;
    this.balance = 0;
  }

  // Getter
  public double getBalance() { return balance; }

  // Setter / behavior
  public void deposit(double amt) { balance += amt; }

  public boolean withdraw(double amt) {
    if (amt > balance) return false;
    balance -= amt;
    return true;
  }
}

Using Objects

// Instantiation
BankAccount acc = new BankAccount("Alice");

// Call methods
acc.deposit(500);
boolean ok = acc.withdraw(200);
System.out.println(acc.getBalance()); // 300

// Array of objects
BankAccount[] accounts = new BankAccount[3];
accounts[0] = new BankAccount("Bob");

// toString override
@Override
public String toString() {
  return name + ": $" + balance;
}
Key OOP Principles
Encapsulation: private fields + public methods
Abstraction: hide complexity
Inheritance: extend classes
Polymorphism: same method, different behavior

static Keyword

public class BankAccount {
  // Shared by ALL instances
  private static double interestRate = 3.5;

  // Class method — no object needed
  public static void setInterestRate(double r) {
    interestRate = r;
  }
}

// Call on class, not object:
BankAccount.setInterestRate(4.0);

Wrapper Classes & Autoboxing

// ArrayList needs objects, not primitives
ArrayList<Integer> nums = new ArrayList<>();

// Autoboxing: int → Integer (auto)
nums.add(42);

// Unboxing: Integer → int (auto)
int x = nums.get(0);

Inheritance & Polymorphism

§08

Inheritance with extends

public class Employee {
  protected String name;
  public Employee(String name) { this.name = name; }
  public String getName() { return name; }
}

public class PartTimeEmployee extends Employee {
  private double hourlyPay;

  public PartTimeEmployee(String name, double pay) {
    super(name); // call superclass constructor (MUST be first)
    this.hourlyPay = pay;
  }

  public double weeklyPay(int hours) {
    return hours * hourlyPay;
  }
}

Method Overriding

// Superclass
public boolean withdraw(double amt) {
  if (amt > balance) return false;
  balance -= amt;
  return true;
}

// Subclass GoldAccount overrides it
@Override
public boolean withdraw(double amt) {
  if (amt > balance + overdraftLimit) return false;
  balance -= amt;
  return true;
}
@Override is optional but recommended — the compiler will catch typos.

Interfaces & Lambda Expressions

§09

Interface

// All methods are public abstract by default
public interface Checkable {
  boolean check();
}

// A class can implement many interfaces
public class MyClass implements Checkable {
  @Override
  public boolean check() {
    return value > 0;
  }
}
Interfaces solve Java's "no multiple inheritance" limitation. A class can implements many.

Lambda Expressions

Functional interface = 1 abstract method
// Anonymous class (old way)
Checkable c = new Checkable() {
  public boolean check() { return true; }
};

// Lambda (new way) — no params
Checkable c = () -> true;

// With param and multiple lines
MyFn fn = (x, y) -> {
  System.out.println("Sum");
  return x + y;
};

// Single return → shorthand
MyFn fn2 = (x, y) -> x + y;

Built-in Functional Interfaces

Function<T,R>apply(T)T → R
Predicate<T>test(T)T → boolean

BinaryOperator<T>apply(T,T)T,T → T

Method References

// Lambda that just calls a method:
str -> System.out.println(str)
// Shorthand with ::

// Static method reference

Generic Class

// T is a type placeholder
public class Box<T> {
  private T value;
  public void set(T v) { value = v; }
  public T get()       { return value; }
}

// Usage
Box<String>  sb = new Box<>();  sb.set("hi");
Box<Integer> ib = new Box<>();  ib.set(42);

Bounded Types & Wildcards

// Upper bound: T must be Calculatable
class Comp<T extends Calculatable> { }

// Wildcard: any type extending BankAccount
void helper(Box<? extends BankAccount> b) {
  // b can be Box
  // or Box, etc.
}
Use <? extends X> for read-only access to a family of types.

Exception Handling

§11

try / catch / finally

try {
  int result = 10 / 0;   // throws!
} catch (ArithmeticException e) {
  System.out.println("Math error: " + e.getMessage());
} catch (Exception e) {   // general catch (last!)
  e.printStackTrace();
} finally {
  // Always runs (cleanup)
}

Try-with-Resources

// Auto-closes resource (no finally needed)
try (Scanner sc = new Scanner(System.in)) {
  String line = sc.nextLine();
} catch (Exception e) {
  e.printStackTrace();
}
// Scanner is closed automatically
Resource must implement AutoCloseable or Closeable.

Throwing Exceptions

// Throw built-in
throw new RuntimeException("Bad input");

// Declare in method signature
public void read() throws IOException {
  // IOException is checked — must handle
}

Custom Exception

public class CustomException
      extends RuntimeException {
  public CustomException(String msg) {
    super(msg);
  }
}

// Throw it
throw new CustomException("Invalid size");

// Catch it
} catch (CustomException e) { ... }

Exception Hierarchy

Multithreading

§13

Creating & Starting Threads

// Lambda as Runnable
Thread t = new Thread(() -> {
  for (int i = 0; i < 10; i++) {
    System.out.println(i);
    try {
      Thread.sleep(1000); // 1 second
    } catch (InterruptedException e) {}
  }
});
t.start();  // NOT t.run()
⚠ Never run long tasks on the JavaFX Application Thread — it freezes the UI.

Spring Boot

§15

What is Spring Boot?

  • Framework for building Java web apps & REST APIs quickly
  • Auto-configuration: detects libraries, configures them for you
  • Embedded Tomcat server — just run a JAR file
  • Starter dependencies: one import bundles everything needed
  • Production-ready via Actuator (health, metrics, logging)

Essential Annotations

AnnotationPurpose
@SpringBootApplicationEntry point — enables everything
@RestControllerClass handles HTTP requests
@GetMapping("/url")Map GET request to method
@PostMapping("/url")Map POST request
@RequestParamExtract URL query param
@RequestBodyParse JSON body to object
@ServiceMark class as service bean
@ControllerAdviceGlobal exception handler
@ExceptionHandlerHandle specific exception

REST Controller Example

@RestController
@RequestMapping("/mtg")
public class MortgageController {

  private final MortgageService svc;

  // Constructor injection
  public MortgageController(MortgageService svc) {
    this.svc = svc;
  }

  @GetMapping("/payment")
  public ResponseEntity<String> pay(
      @RequestParam double principal,
      @RequestParam int years,
      @RequestParam double interest) {
    String result = svc.calculate(principal,years,interest);
    return ResponseEntity.ok(result);
  }
}

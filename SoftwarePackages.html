7 Phases of the Software Lifecycle

SDLC

1. Planning

  • Define purpose & goals
  • Identify stakeholders
  • Allocate budget/team
  • Feasibility analysis

2. Requirements

  • Functional: what it does
  • Non-functional: performance, security
  • Interviews, surveys

3. Design

  • UI: visual elements
  • UX: user experience
  • System architecture
  • Data flow diagrams

4. Development

  • Write source code
  • Version control (Git)
  • CI/CD pipelines
  • Team collaboration

5. Testing

  • Unit → Integration → System
  • UAT (end-user testing)
  • Tools: Selenium, JUnit, Postman

6. Deployment

  • Move to production
  • Install packages / scripts
  • Roll out to users

7. Maintenance

  • Bug fixes
  • Feature updates
  • User support

8. Retirement

  • Phase out features
  • Data migration
  • Archive/deactivate
Architecture patterns: Client-Server (tasks split between server & client) | Microservices (small independent services) | Monolith (everything together). CI/CD = Continuous Integration/Continuous Deployment — push small changes frequently.

📊 Excel — Scenario Analysis & Forecasting
🎯

Goal Seek

Data → What-If Analysis → Goal Seek
Idea: "What input do I need to reach a target output?"
Example: To hit $50,000 profit, what sales volume do I need?
FieldWhat to enter
Set cellCell with the formula (e.g. D9 = result)
To valueThe target number you want (e.g. 100)
By changing cellThe input cell Excel will adjust (e.g. C9)
The target cell must contain a formula. Goal Seek works backwards from result → input.
📋

Scenario Manager

Data → What-If → Scenario Manager
Idea: Define multiple "what if" situations (Best/Worst/Expected) and switch between them instantly.
  1. Data → What-If Analysis → Scenario Manager
  2. Click Add → name your scenario (e.g. "Best Case")
  3. Select changing cells → enter their values
  4. Repeat for each scenario
  5. Click Show to switch; click Summary for a comparison report
Max 32 variables per scenario. For more variables → use Data Tables.
📉

Data Tables

See ALL outcomes at once

Unlike Scenario Manager (switch one at a time), Data Tables show all results simultaneously in a grid.

  1. Set up your formula in a cell (e.g. =B5 for Total Revenue)
  2. Create a column of input values (e.g. 0%, 5%, 10%...)
  3. Select the range (inputs + formula cell)
  4. Data → What-If Analysis → Data Table
  5. Enter Column Input Cell (the variable cell, e.g. B3)
🔮

Forecast Sheet

Data → Forecast Sheet
Uses historical data to predict future trends automatically.
ElementMeaning
Blue lineActual historical data
Orange linePredicted future values
Gray shaded areaConfidence interval (uncertainty range)

Settings: Forecast End date, Confidence Interval (default 95%), Seasonality (auto-detect or manual), missing point interpolation.

⚡ Excel Macros & VBA
⚡

What is a Macro?

A macro is a recorded sequence of actions that Excel can replay automatically — no manual repetition needed.

TYPE 1 — Recorded Macro

  • ✅ No coding needed
  • ✅ Record actions via UI
  • ❌ Limited logic

TYPE 2 — VBA Macro

  • ✅ Full programming power
  • ✅ Loops, conditions
  • ❌ Requires VBA knowledge
🎬

Recording & Running a Macro

Record: View → Macros → Record Macro → do your actions → Stop Recording

Run: Press assigned shortcut key OR View → Macros → View Macros → Run

Edit VBA: Press Alt + F11 to open the VBA editor

' Example: VBA macro to bold and color cells
Sub FormatCellsMacro()
    With Range("A1:B5")
        .Font.Bold = True
        .Font.Color = RGB(0, 0, 139)  ' Dark blue
        .Interior.Color = RGB(255, 255, 200)  ' Light yellow
    End With
End Sub
🐼 Python + Excel — Pandas
🐼

Pandas — Reading & Writing Excel Files

pip install pandas openpyxl

📝 Create & Save Excel File

import pandas as pd
import os

# Define data as a dictionary
data = {
  "Date": ["2025-01-01"],
  "Region": ["North"],
  "Product": ["Laptop"],
  "Quantity": [5],
  "Price": [1200]
}

df = pd.DataFrame(data)  # dict → table
df.to_excel("sales.xlsx", index=False)

🔍 Read & Filter

df = pd.read_excel("sales.xlsx")
filtered = df[df["Region"] == "North"]
filtered.to_excel("north_sales.xlsx", index=False)

➕ Append New Rows

df_old = pd.read_excel("sales.xlsx")

new_row = pd.DataFrame([{
  "Date": "2025-03-23",
  "Region": "East",
  "Product": "Monitor",
  "Quantity": 4,
  "Price": 365
}])

combined = pd.concat(
  [df_old, new_row],
  ignore_index=True  # reset row numbers
)
combined.to_excel("sales.xlsx", index=False)

🔤 Format Data

df.columns = df.columns.str.upper()
df["PRODUCT"] = df["PRODUCT"].str.title()
# .str.upper() → "laptop" → "LAPTOP"
# .str.title() → "laptop" → "Laptop"
Key concepts: pd.DataFrame(dict) = create table | index=False = don't write row numbers to file | ignore_index=True = reset row numbers after concat | engine="openpyxl" = specify .xlsx handler explicitly

📂 OpenPyXL — Advanced Excel Control
📂

OpenPyXL Basics

pip install openpyxl
Use OpenPyXL when you need full control over Excel: cell styling, colors, borders, formulas, charts. Only works with .xlsx (not .xls). 
from openpyxl import Workbook

wb = Workbook()         # create new workbook
ws = wb.active           # get the default sheet

ws.append(["ID", "Name", "Salary"])  # header row
ws.append([1, "Ana", 4500])           # data row

wb.save("report.xlsx")
# Open EXISTING file
from openpyxl import load_workbook

wb = load_workbook("report.xlsx")
ws = wb.active
ws.append([2, "Ion", 5200])
wb.save("report.xlsx")
🎨

Cell Styling — Highlight Rows

from openpyxl import load_workbook
from openpyxl.styles import PatternFill

wb = load_workbook("salaries.xlsx")
ws = wb.active

# Create a green fill style
green = PatternFill(
  start_color="C6EFCE",   # hex color (light green)
  end_color="C6EFCE",
  fill_type="solid"
)

# Loop through rows (skip header row 1)
for row in ws.iter_rows(min_row=2, max_col=6):
  total = row[5].value  # 6th column (index 5)
  if total and total > 5000:
    for cell in row:
      cell.fill = green

wb.save("salaries.xlsx")
iter_rows(min_row=2) skips the header | row[5] = column index (0-based) | PatternFill needs start_color, end_color, and fill_type

🔍 Software Selection & Usage Strategies
🔍

8 Selection Criteria

1. Functional Requirements

Does it do what you need? Are features customizable?

2. Usability

Is the UI clean and intuitive? Good tutorials?

3. Compatibility

Works with existing systems? API available? Import/export formats?

4. Performance & Reliability

Speed, uptime, efficiency with CPU/memory.

5. Security

Encryption, auth, GDPR/ISO 27001 compliance.

6. Cost & Licensing

Total Cost of Ownership (TCO). Subscription vs. perpetual vs. open-source.

7. Vendor Reputation

Is the provider stable? Support? Training available?

8. Scalability

Can it grow with you? Migration options for the future?

⚖️ IP Law & Software Licenses
⚖️

4 Types of IP Protection

TypeProtectsKey Point
Copyright Source code, UI elements, object code Automatic on creation. Protects expression, NOT ideas/algorithms.
Patent Technical inventions Up to 20 years. Expensive. US = can patent software; EU = harder.
Trade Secret Confidential algorithms No registration. E.g. Google's search algorithm, Netflix recommender.
Trademark Names, logos, slogans "Windows", Apple logo, "There's an app for that"
Oracle vs. Google (2021): Google used Java APIs in Android. Supreme Court ruled it was fair use — transformative + limited use. APIs can be used for compatibility without copyright infringement.
Snapchat vs. Instagram: Instagram copied the idea of Stories — legal! Copyright only protects the code, not the concept.
📜

Software License Types

License TypeCan Modify?Can Share?Example
Proprietary ❌ No ❌ No Windows, Adobe CC
MIT / Apache 2.0 (Permissive) ✅ Yes ✅ Yes (even proprietary) React, Angular
GNU GPL (Copyleft) ✅ Yes ✅ Yes — but must stay GPL Linux, WordPress
SaaS / ToS N/A Access-based, no code ownership Google Docs, Notion
Key license clauses: Grant of Rights | Restrictions | Termination | Warranty Disclaimer ("as-is") | Limitation of Liability
Romania: Software protected under Law 8/1996 — classified as a literary work. Aligned with Berne Convention, WIPO Copyright Treaty, TRIPS Agreement.
